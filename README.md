# 🎯 目標実現アプリ

資格取得・学力向上・仕事のスキル習得のための学習アプリです。
「全体像 → 体系的な理解 → 練習 → 間隔反復で定着 → 本番想定テスト」を1つのアプリで回します。

## 使い方

1. `index.html` をブラウザ（**Microsoft Edge または Google Chrome 推奨**）で開く
   - サーバー不要。ダブルクリックで動きます
2. ホームでコースを選び、**現在のレベル・目標・目的・1日の学習時間・目標日**を設定
3. コース画面の「全体像」で地図を頭に入れてから、「次にやること」に沿って進める
4. 毎日、ホームの「今日のミッション」（復習 → 新しいレッスン）をこなす

> 学習記録はブラウザ内（localStorage）に保存されます。ブラウザのデータ削除で消えるので、
> 「設定 → バックアップを保存」で定期的に保存してください（別PCへの移行にも使えます）。

## 学習の仕組み

- **全体像とスキルマップ**：各コースの冒頭に全体の構造図。ユニットは前提関係でつながったマップで表示
- **目的別ルート**：選んだ目標に直結するユニットに ★。開始ステージ以降の未習得ユニットを順に提案
- **診断テスト**：各ステージから出題し、最適なスタート地点を判定
- **レッスン**：図解つき。英文は 🔊 で読み上げ（Edge の「Natural」音声が最も自然）
- **練習問題**：選択・入力（数値は許容誤差つき）・並べ替え・ディクテーション・スピーキング（音声認識）
- **間隔反復（SRS）**：解いた問題とカードは、忘れかけるタイミングで自動的に復習に出題
- **習得認定テスト**：ユニットの全問を解説なしで解き、90%以上で 👑
- **模試**：時間制限つき。英語は推定スコア、他は合格ライン判定
- **続ける仕組み**：XP・レベル・称号、連続学習日数、今日の目標、コンボ、バッジ、学習ヒートマップ
- **📚 多読ライブラリ**（`#/read`）：Lv1〜5 の読み物。点線の語をタップすると意味が出て、1タップで単語帳（復習）に追加できる。読了すると WPM（1分あたりの語数）・累計語数を記録し、理解チェックの問題と「この話の単語・フレーズ」一覧を表示
- **🔤 単語ジム**（`#/words`）：英語の全単語帳を「よく出る順」に並べ、定着数・学習中・今日の復習を表示。単語を効率よく覚える作戦（頻出語から／思い出す練習／間隔反復／多読で再会／部品とセット）の解説つき

- **⚡ 速読ジム**（`#/speed`）：速読のトレーニング13種。最初に「速度測定」でベースライン（実効速度＝速さ×理解度）を測り、以後は**精読・把握・探索**の3つの倍率で伸びを表示
  - 計測：速度測定（読むのが速すぎる結果はベースラインに使わない）
  - 目と視野：視点移動（★反応チェック）・シュルツテーブル・視幅拡大／瞬間数字
  - 瞬間認識：瞬間フレーズ・バラバラ文字（正解すると表示が短く・長くなる適応型）
  - 流れ：高速表示（RSVP）・ペーサー読み（返り読み禁止モード）
  - 把握：スキミング（ベースラインの×2〜×30の制限時間）・スキャニング・高速多回転読み（3回転）・キーワード・フラッシュ
  - 成果：1分アウトプット・実書籍トレーニング（目的→下見→3回転→付箋だけ精読→アウトプット。1冊の時間と換算速度を記録）
  - 15分／30分の「今日のメニュー」と30日プログラムを表示。日本語の練習文36本（うち長文4本）に加え、英語の多読ライブラリ60話も練習文として使える

- **🗣 英語ジム**（`#/egym`）：英語を口と手から出す練習。例文バンク170文（13の型：5文型・時制・完了・助動詞・受動態・準動詞・関係詞・接続詞・比較・仮定法・ビジネス・海外・技術説明）
  - 瞬間英作文：日本語を見てすぐ英語に。単語を並べるモード／自分で打つモード。まちがえた文・まだ言えない文を優先して出題し、正解後に音声を流す
  - ディクテーション：音声を書き取り、聞き取れなかった単語を赤で表示（長さ・速さを選べる）
  - シャドーイング：聞く → 文字を見て重ねる → 文字を隠す → リピーティング。例文のほか、多読ライブラリの60話も教材になる
  - Part 5 タイムアタック：空所補充を1問20秒で20問。分野ごとの正解率と、まちがえた問題の解説を最後に表示
- 速読ジムのトップに**成長グラフ**（日ごとの最高倍率を、精読・把握・探索の3本の線で表示）

- **🏯 日本史ナビ**（`#/jhist`）：日本史コースの122のできごとを「原因 → 結果」の矢印でつないだデータを使う練習の場
- **📈 経営シミュレーション**（`#/bizsim`）：AI検査装置の会社の社長になり、12四半期（3年）を経営する。四半期ごとに価格・営業と技術者の人数・開発の重点（品質／原価低減／導入の簡単さ）・広告・借り入れ・出資を決める。装置の代金は「納品した四半期に3割、次の四半期に7割」入るため、売れるほど先に現金が出ていく（運転資金）。入力のたびに「見こみ」（引き合い・受注率・納品の上限・1台の限界利益・損益分岐点）を表示。途中で5つの出来事（大口の引き合い・競合の参入・部品の値上がり・引き抜き・補助金・投資家・品質の評判から毎回ちがう組み合わせ）が起きる。期末の現金がマイナスになると終了。成績は「会社の価値 × 自分の持ち分」で、最後に資金・損益分岐点・価格・経験曲線・ボトルネック・出資についての講評と、関連ユニットへのリンクを表示。途中経過は保存され、続きから再開できる。計算の本体は `LearnApp.bizsimModel`（画面なしで動かせる）
  - 流れアニメ：年表の上を自動で進みながら、できごとごとに「なぜ起きた？／何につながった？」を表示（時代の範囲・速さを選べる）
  - つながりマップ：1つのできごとを中心に、左に原因・右に結果。タップでたどれる
  - テーマの線：政治の担い手・土地と税・外交・経済・文化の5本で、全時代を縦に通して表示
  - 並べ替えチャレンジ：4つのできごとを古い順に（時期に幅のあるできごとは出題しない）

キーボード操作：選択肢は `1`〜`4`、カードは `Space` で裏返し `1`〜`4` で評価、`Enter` で次へ。

## コースの追加方法（誰でも追加できます）

1. `courses/` に新しいファイル（例：`courses/fe-exam.js`）を作る
2. `index.html` の「コース」欄に `<script src="courses/fe-exam.js"></script>` を1行追加
3. ブラウザを再読み込み

### コースを作る前に決めること

- **現在地**（levels）：学習者がどのレベルから始めるか
- **目標**（goals）：何ができるようになれば達成か（複数可。ユニットの tags と対応）
- **全体像**（overview）：分野全体の地図。部分ではなく全体の構造が先にわかるように
- **ステージ**（stages）：基礎 → 応用 → 実践のように、積み上げの順序

```js
(function () {
  LearnApp.registerCourse({
    id: 'fe-exam',                 // 英数字の一意なID（後から変えると記録が引き継がれない）
    title: '基本情報技術者',
    icon: '💻',
    color: '#0ea5e9',
    tagline: '一行の説明',
    purposeHint: '目的入力欄の例文',
    setupNote: '設定画面に出すアドバイス（任意）',
    levels: [
      { id: 'zero', label: '初心者', desc: '説明', stage: 0 },   // stage = 開始ステージ番号
      { id: 'mid',  label: '経験あり', desc: '説明', stage: 1 },
    ],
    goals: [
      { id: 'pass', label: '試験に合格', desc: '説明' },
      { id: 'work', label: '業務で使う', desc: '説明' },
    ],
    stages: [
      { title: '基礎', desc: 'このステージの説明' },
      { title: '応用', desc: '...' },
    ],
    overview: `<p>全体像の説明（HTML）。図解は下の「図の書き方」参照</p>`,
    units: [
      {
        id: 'fe-1', stage: 0,
        core: true,                // true：目標の選択にかかわらず必修
        tags: ['pass'],            // 対応する goals の id（★表示・ルートに反映）
        pre: [],                   // 前提ユニットの id（スキルマップの線）
        title: 'ユニット名',
        sum: '一行の要約',
        goals: ['このユニットで「できるようになること」'],
        lessons: [
          { title: 'レッスン名', min: 15, html: `<p>本文（HTML）</p>` },
        ],
        qs: [
          // 選択問題：c=選択肢、a=正解の番号（0始まり）、e=解説
          { q: '問題文', c: ['正解', '誤り1', '誤り2', '誤り3'], a: 0, e: '解説' },
          // ○×問題
          { t: 'tf', q: '文章', a: false, e: '解説' },
          // 入力問題（文字）：大文字小文字・前後の空白・句読点は無視。配列で別解も可

          // 入力問題（数値）：tol=許容誤差（省略時は ±1%）、suffix=単位表示
          { t: 'input', q: '問題文', answer: 0.05, tol: 0.001, suffix: 'mm/px', e: '解説' },
          // 並べ替え：tokens は正しい順に書く（表示時にシャッフル）
          { t: 'order', q: '日本語訳', tokens: ['I', 'have', 'a', 'pen'], e: '解説' },
          // 書き取り（英語）：audio を読み上げ、入力と照合
          { t: 'dict', q: '聞いて書き取ろう', audio: 'Could you send it to me?', e: '解説' },
          // スピーキング（英語）：音声認識、使えない環境では自己評価
          { t: 'speak', q: '言ってみよう', text: 'Nice to meet you.', ja: 'はじめまして', e: '解説' },
          // 共通オプション：passage（問題の上に表示する長文HTML）、audio（選択問題で音声を流す）、
          //                 shuffle:false（選択肢を並べ替えない）、hint（ヒント）
        ],
      },
    ],
    decks: [   // 単語・用語カード（任意）。say:true で表面を英語読み上げ
      { id: 'words', title: '重要語', say: false, cards: [['表', '裏', '例文（任意）']] },
    ],
    exams: [   // 模試（任意）
      {
        id: 'mock1', title: '本番形式模試', minutes: 60, pass: 0.6,   // score:'toeic' でTOEIC推定
        sections: [
          { title: '午前', units: ['fe-1'], count: 20 },              // units 省略で全ユニット

```

### 注意点

- 問題の記録は「ユニットID＋問題の順番」で管理されます。**既存の問題の途中に挿入せず、末尾に追加**してください（途中に入れる場合は各問題に `id: 'q-xxx'` を付けると安全です）
- テンプレート文字列（`` ` ``）の中では `` ` `` と `${` を使わないでください
- 英文に `<span class="say">英文</span>` と書くと 🔊 ボタンが付きます

### 授業の型（新しいレッスンはこの形で書く）

教科書の説明ではなく「一流の講師の授業」として書きます。レッスンは `html` の代わりに `steps`（授業の流れ）で書き、読む → 確認 → 次へ、と進みます。

**1レッスンの流れ**

1. **フック**：問い・意外な事実・格言から入る（「犬が男をかんだ、と男を犬がかんだ。なぜ意味が同じ？」）
2. **正体を一言で**：本質を短く言い切る（「英語は席順で役割が決まる」）
3. **たとえ・図**：身近なもので納得させる（夜道の懐中電灯 ＝ 暗視野）
4. **すぐ確認**：理解したかを1問で確かめる。誤答ごとに「なぜ違うか」を書く
5. **決め台詞**：一言で言える要点にまとめる（自動で「決め台詞カード」になる）
6. **ひっかけ注意**：よくある勘違いを先回りして潰す
7. **実務でどう効くか**：試験・仕事のどこで使うかを伝えて締める

**文体のルール**：です・ます調の話し言葉。1つの吹き出しに伝えることは1つ。専門用語は初出で必ず言い換える。「覚えろ」ではなく「なぜそうなるか」を言う。

```js
lessons: [{ title: '…', min: 12, steps: [
  { t: 'talk', html: '講師の語り' },                 // 吹き出し
  { t: 'html', html: '<div class="fig">…</div>' },    // 図・表・例
  { t: 'q', q: { q: '…', c: ['正解', '誤り'], a: 0, why: ['', 'この誤りを選んだ人への一言'], e: '解説' } },
  { t: 'key', front: '問い', back: '一言の答え' },     // 決め台詞（カードになる）
  { t: 'trap', html: 'よくある勘違い' },               // ひっかけ注意
] }],
```

**問題の設計**

- `lv: 1 / 2 / 3`（基礎・標準・応用）を付ける。練習は自動で基礎 → 標準 → 応用の順に出る
  - 基礎：用語と原理を「知っている」か
  - 標準：似たものを「見分けられる」か（ひっかけを含む）
  - 応用：実務の文・計算・判断で「使える」か
- 選択問題には `why`（選択肢ごとの「なぜ違うか」）を書く。誤答の理由が、一番学びになる
- 問題には `id` を付ける（`id: 'b1'` など）。並べ替えても学習記録が保たれる

**実践課題（missions）**

```js
missions: [{ title: '…', time: '30分', why: 'なぜやるのか（講師の言葉で）',
  steps: ['手順1', '手順2'], deliverable: '成果物', criteria: ['合格基準1', '合格基準2'] }],
```

```html
<div class="box tip"><b>コツ</b>本文</div>          <!-- 緑：ヒント -->

```

### 図の書き方（SVG）

`<div class="fig"><svg viewBox="0 0 600 200" width="600"> ... </svg><p class="cap">図の説明</p></div>`

ライト／ダークどちらでも見えるよう、色は次のクラスで指定します。

| クラス | 意味 |
|---|---|
| `l` / `l2` / `la` / `lg` / `lr` / `lw` | 線（黒 / 灰 / 青 / 緑 / 赤 / 黄）。`dash` で破線 |
| `f0` / `f1` / `fa` / `fg` / `fr` / `fw` | 塗り（白 / 灰 / 淡青 / 淡緑 / 淡赤 / 淡黄） |
| `fA` / `fG` / `fR` / `fW` / `fI` | 塗り（濃い青 / 緑 / 赤 / 黄 / 文字色） |
| `tm` / `b` / `s` / `ta` / `tg` / `tr` | 文字（中央揃え / 太字 / 小さく / 青 / 緑 / 赤） |
| `marker-end="url(#ar)"` | 矢印（`#ara` で青い矢印） |

例：`<rect x="10" y="10" width="100" height="40" rx="6" class="l fa"/>`

### 図解ヘルパー（短く書ける定番の図）

コースファイルの先頭で `const D = LearnApp.D;` とし、ステップに `{ t: 'html', html: D.flow(...) }` のように置きます。どれも最後の引数 `{ cap: '図の説明' }` で説明文を付けられます。

| ヘルパー | 用途 | 例 |
|---|---|---|
| `D.flow(items, o)` | 横の流れ（`o.loop` で戻り矢印） | `D.flow([['聞く','ヒアリング','👂'], ['見る','評価','👀']])` |
| `D.compare(L, R, o)` | 左右の比較 | `D.compare({title, icon, lines:[], color:'fa'}, {...}, {vs:'vs'})` |
| `D.icons(items, o)` | 絵文字のイラスト並び（`o.sep: '→'`） | `D.icons([['🍲','母集団','鍋全体']])` |
| `D.chunks(parts, o)` | 英文のカタマリ（`o.slash`） | `D.chunks([['The system','主語','fa']])` |
| `D.cycle(items, o)` | 輪（`o.center`） | `D.cycle([['監視','NG率'], ['集める','']])` |
| `D.grid(cols, rows, cells, o)` | マス目の表 | `D.grid(['A','B'], ['行1'], [[['文字','fg'], ['', 'f1']]])` |
| `D.bars(data, o)` | 棒グラフ（`o.cum` でパレート図） | `D.bars([['傷',45], ['打痕',25,true]], {unit:'件'})` |
| `D.scale(items, o)` | 強さの目盛り（`o.left` / `o.right`） | `D.scale([['might',''], ['must','']])` |
| `D.stack(items, o)` | 積み重ね（上から順） | `D.stack([['自分のコード',''], ['GPU','']])` |
| `D.svg(inner, w, h, cap)` | 自由に描く SVG を枠で包む | — |

方針：**1レッスンに最低1枚**。文字で説明する前に、絵で「あ、そういうことか」と思わせる位置に置きます。

## 多読の読み物・単語帳の追加方法

### 読み物を追加する
`readers/` に `.js` ファイルを作り（既存の `lv1.js` などに足してもよい）、`index.html` の「多読ライブラリ」欄に1行足します。

```js
LearnApp.addReadings([
  {
    id: 'my-story',            // 一意のID（URLになる）
    lv: 2,                     // 1〜5
    emoji: '🚀', genre: '科学',
    title: 'English Title', ja: '日本語の題',
    sum: '読み終わってから表示する日本語のあらすじ',
    text: ['第1段落...', '第2段落...'],
    gloss: [['noticed', 'notice', '気づく'], ['strange', '奇妙な']], // [本文の形, 見出し語, 意味] or [語, 意味]
    phrases: [['turned out', 'わかった（turn out）']],            // [本文の形, 意味]。'pull ... off' のように ... で間を飛ばせる
    qs: [{ q: '質問', c: ['正解', '誤り1', '誤り2'], a: 0, e: '解説' }], // 選択肢は表示時にシャッフルされる
  },
]);
```

- `gloss` と `phrases` の語は本文中で自動的に点線になり、英語コースの「多読の単語帳」にも自動で入ります（何話に登場するかを数え、多い順に出題）
- 本文の形が本文中に見つからないと点線になりません。追加後は1度開いて確認してください
- 語数は自動で数えます。目安：Lv1 〜200語、Lv2 約250語、Lv3 約330語、Lv4 約400語、Lv5 約500語

### 既存コースにユニット・問題・模試を足す

コースの本体ファイルを触らずに、別ファイルから足せます（`index.html` で本体より後に読み込む）。

```js
LearnApp.addUnits('speed', [{ id: 'sp-new', stage: 2, pre: ['sp-grasp'], title: '…', lessons: [...], qs: [...] }]);
LearnApp.addQuestions('english', { 'en-tense': [{ id: 'x1', lv: 1, q: '…', c: ['正解', '誤り', '誤り'], a: 0, e: '解説' }] });  // id は元の問題と重ならないよう x で始める
LearnApp.addExams('speed', [{ id: 'speed-check', title: '…', minutes: 15, pass: 0.7, sections: [{ title: '…', units: ['sp-truth'], count: 5 }] }]);
LearnApp.addSentences([['p1', '私はエンジニアです。', 'I am an engineer.']]);   // 英語ジムの例文（型のid, 日本語, 英語）
```

### 単語帳を追加する（既存コースに足す）
```js
LearnApp.addDecks('english', [
  { id: 'my-deck', title: '単語帳の名前', say: true, group: 'core', desc: '説明', cards: [['word', '意味', 'Example sentence.']] },
]);
```
`group` を付けた単語帳はコース画面のボタンには出ず、単語ジムにまとめて表示されます。

## 速読ジムの練習文の追加方法

`speed/` フォルダに練習文を足し、`index.html` に `<script src="speed/ファイル名.js"></script>` を1行足します。

```js
LearnApp.addSpeedTexts([
  {
    id: 'my-text', title: 'タイトル', genre: 'ジャンル',
    body: ['段落1', '段落2'],                        // 700〜2000字くらい
    q:  [{ q: '詳細の問題', c: ['正解', '誤り', '誤り', '誤り'], a: 0, e: '解説' }],   // 3問：速度測定・ペーサー・RSVP・3回転目
    g:  [{ q: '要旨の問題', c: [...], a: 0 }],          // 2問：スキミング・2回転目
    kw: ['本文に出る言葉', ...6個],                     // キーワード・フラッシュ・1回転目
    nk: ['本文に出ない言葉', ...6個],                   // ↑のダミー（本文に含まれていないこと）
    sc: [{ q: '探す問題（何年？など）', c: [...], a: 0 }], // 3問：スキャニング
  },
]);
```
選択肢は表示のたびに並べ替わるので、正解は先頭（`a: 0`）に書いてかまいません。

## 日本史コースの部品（漫画・アニメーション）

`js/history.js` が `LearnApp.H` を用意します（日本史コースより先に読み込む）。どれも HTML 文字列を返すので、レッスンの `{ t: 'html', html: ... }` に入れて使います。すべてに「↻ もう一度」ボタンが付き、アニメーションを再生し直せます。

| 部品 | 書き方 | 内容 |
|---|---|---|
| 漫画 | `H.manga([{ nar, tone, fx, props, ch: [[絵文字, 名前, セリフ, 'r'/'shout'/'think']] }], { title })` | コマが順に現れる。`tone`：a/w/g/r（背景色）、`fx`：burst（集中線）・shake・dark |
| 因果のくさり | `H.chain(['konden', 'shoen', ...], { links, goal })` | できごとの id か `[絵文字, 見出し, 説明, 年, 矢印の言葉]`。矢印の言葉を省くと、データ上の因果なら「だから」、それ以外は「その後」 |
| 地図 | `H.map({ pts: [[地名]], routes: [{ p: [地名, ...], c, label }] })` | 略地図。地名は `H.place` に登録済みのもの、または `[地名, 経度, 緯度, 絵文字]` |
| 年表 | `H.tl(['perry', ...])` | 動く印が左から右へ進み、項目が順に現れる |
| 人物カード | `H.people([{ e, name, life, role, did: [...] }])` | |
| 場面のイラスト | `H.scene([[絵文字, x%, y%, 大きさ, ラベル]], { bg })` | |
| テーマの線 | `H.themeChain('tochi', 開始年, 終了年)` | できごとデータから自動で作る |

できごとと因果のデータは `js/history.js` の `RAW`（`[id, 年, 年の表示, 名前, 絵文字, ユニット, つながる先, テーマ, ひとこと]`）。ここに足すと、日本史ナビと年代カードに自動で反映されます。

## スマホで使う（ホーム画面に追加・電波なしでも動く）

このアプリは、スマホのホーム画面に入れて、ふつうのアプリのように使えます（PWA）。一度開いておけば、地下鉄など電波のない場所でも動きます。

### しくみ
- `manifest.json` と `icons/`：ホーム画面に入れたときの名前・アイコン・色
- `sw.js`：最初に開いたとき、`index.html` に書かれているファイル（デザイン・プログラム・教材）をすべて端末に保存する。**一覧は `index.html` から自動で読み取る**ので、教材を足しても `sw.js` を直す必要はない
- ふだんは「保存してある内容をすぐ表示 → 裏で新しい版を確認」。新しい版があれば保存を入れかえ、画面の下に **「新しい内容があります」** と出す。「更新する」を押すと新しい内容に切りかわる（学習記録は消えない）
- `js/pwa.js`：上の仕組みの登録と、設定画面の「📱 スマホで使う」（状態・ホーム画面への追加の手順・「最新の内容を確認」ボタン）
- 図解（流れ・積み重ね・アイコン並び・左右の比較）は、画面がせまいと自動で縦にならぶ

### 使える条件（大事）
オフライン機能とホーム画面への追加は、ブラウザの決まりで **https で公開した場所**（または自分のPCの `localhost`）でしか働きません。同じ Wi-Fi から `http://192.168.…:8793` で開いた場合、画面は見られますが、オフラインでは動きません。**通勤中に使うには、下の方法でネットに公開します。**

### ネットに公開する
このフォルダの中身をそのまま置くだけで動きます（サーバー側のプログラムは不要）。どれも無料で使えます。

| 方法 | 手順 | 更新のしかた |
|---|---|---|
| **GitHub Pages** | GitHub にリポジトリを作り、このフォルダの中身を入れる → リポジトリの Settings → Pages → Branch を `main`（`/root`）にして保存 → 数分後に `https://ユーザー名.github.io/リポジトリ名/` で開ける | 変更を GitHub に送る（push）と、数分で反映される |
| **Cloudflare Pages** | Cloudflare に登録 → Workers & Pages → Pages → 「Upload assets」でこのフォルダをアップロード（GitHub と連携して自動で反映させることもできる） | フォルダをもう一度アップロードする（GitHub 連携なら push するだけ） |
| **Netlify** | Netlify に登録 → フォルダをドラッグ＆ドロップ | フォルダをもう一度ドラッグする |

- 公開すると、**URL を知っている人はだれでも開けます**。入っているのは教材だけで、学習記録は各自の端末の中にしか保存されません
- 無料の GitHub Pages は、リポジトリを公開（public）にする必要があります。人に見られたくない場合は、Cloudflare Pages と Cloudflare Access（ログインした人だけに見せる機能）の組み合わせなどを使います
- **公開する URL は、途中で変えない**こと。学習記録は URL ごとに保存されるので、変えると引きつがれません（バックアップから復元はできます）

### 学習記録について
- 記録は、**その端末のそのブラウザの中だけ**に保存されます。パソコンとスマホの記録は別々です
- 移すときは、設定画面の「バックアップを保存」→ もう一方の端末で「バックアップから復元」
- iPhone の Safari は、長く使っていないサイトの記録を消すことがあります。**ホーム画面に追加して使う**と、その心配が小さくなります。念のため、ときどきバックアップを保存してください

### 自分のPCで試すとき
`localhost` では、作業しやすいように「いつも最新のファイルを読む（つながらないときだけ保存分を使う）」動きにしています。本番と同じ動き（保存分を先に表示して、裏で更新を確認）を試すときは、アドレスに `?cachefirst` を付けて開きます（例：`http://localhost:8793/?cachefirst`）。
